# Engineering decisions

- 2026-11-07: retain prototype in history and source reference; new runtime mounts none of its insecure Vercel handlers. One persistent Fastify process serves SPA, browser and Twilio WebSockets. Active sockets are process-bound, durable records live in Postgres.
- pnpm workspace, React 18/Vite, Fastify, Drizzle/Postgres and pg-boss. Queue shares Postgres; QStash and Redis are unnecessary.
- Read Gnani index and current STT streaming, TTS SSE, languages, voices and Agent Builder model documentation before implementing adapters. Endpoint `wss://api.vachana.ai/stt/v3/stream`, `x-api-key-id`, signed PCM16LE mono, exactly 1024 bytes paced at 64ms for 8kHz. `processing` indicates speech end, `transcript` is final; do not invent partial events. Timbre SSE `https://api.vachana.ai/api/v1/tts/sse`, `X-API-Key-ID`, `chunk.audio` base64, `complete` event. `container:mulaw` forces 8kHz. v3.0 voice Shivani is documented multilingual. Use explicit language codes.
- Gnani now documents an Agent Builder API and model configuration. This implementation intentionally owns the conversation and uses a separately configured Sarvam/OpenAI-compatible text model; Prisma and Timbre supply speech only. Agent Builder is not used and no claim is made about Evon.
- Defaults select Gnani. Offline mode requires explicit `MOCK_MODE=true`; never automatically switch to mocks on provider failure. Mock output is marked simulation throughout.
- Recording stays disabled. Persist redacted transcript text, not raw audio. HR sensitive utterances are dropped before persistence/model history using conservative filtering; this is a defense, not a guarantee of comprehensive sensitive-data detection.
- Fly official region list currently includes Singapore `sin`, not Mumbai: https://docs.fly.io/reference/regions . Choose Singapore provisionally; measure network latency after credentials and deployment exist. No nearest-endpoint latency claim.
- Calling windows use Asia/Kolkata and may cross midnight. The operator must choose hours consistent with each recipient's consent and preferences. No registry scrubbing is claimed; national DLT/NCPR/TRAI obligations belong to the operator.
- Live credentials, actual provider measurements, managed backup configuration and public deployment require human-owned accounts. Record unrun checks explicitly.
- Current registry audit exposed advisories in the initial dependency selections. Updated to patched Zod 4.6.7, Drizzle 0.45.4, Fastify static 10.1.10 and React Router 7.18.5; migrated records/defaults and native JSON-schema generation accordingly. Production dependency audit returned zero advisories after these updates. This is a point-in-time registry result, not a security certification.
- `pg-boss` uses session/advisory-lock behavior: deploy with a direct or session-mode Postgres connection, not a transaction-mode pooled endpoint. Production PITR still requires provider-console setup and a restore test.
- Grounding is intentionally extractive: novel factual sentences are rejected in favor of team follow-up. Campaign authors supply approved native-script facts/questions. This reduces fluent paraphrasing and needs live multilingual evaluation; do not claim automatic faithful translation.
- Structured dialogue JSON is validated before sentence-level TTS. This adds latency compared with speaking unvalidated token deltas, but avoids speaking a tool/guardrail violation before validation. Audio is still returned as streaming μ-law frames, cancellable after the mandatory disclosure.
- Local observed checks: 80 automated tests before final hardening, desktop and mobile Playwright flow, Docker build and local-container smoke. Four synthetic local Twilio streams completed with zero failures; exact scope is in LOADTEST.json. No live Gnani/Twilio call, external receiver delivery or public Fly deploy was performed.

- Final local suite: 83 tests, including signed-cookie tampering and browser usage/kill-switch reservations. Edit flow keeps workflow type fixed; active calls persist a configuration snapshot and contextual agent version. Public staging remains unverified without accounts.
